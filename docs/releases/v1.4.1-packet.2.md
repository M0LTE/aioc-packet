## What's new in 1.4.1-packet.2

- **The equaliser is now on by default** with the `k5-red` profile, so flashing `aioc-packet-1.4.1-packet.2.bin` is all the AIOC needs for packet with a UV-K5 running quansheng-packet. No tool to run.
- **Fewer files.** The separate `-k5-red` image is gone: the main `.bin` is that image now. If you want the equaliser off, use stock AIOC firmware, or switch it off with `tools/aioc_eq.py off --store`.
- **Upgrading with `-keep-settings`** keeps your stored settings. If they were stored by stock AIOC firmware, the equaliser now comes on; if you stored it off with this release or later, it stays off. Settings stored by 1.4.1-packet.1 with the equaliser on stay on; stored with it off, they come on, so run `aioc_eq.py off --store` afterwards if you want it off.
- The README now leads with the two-step setup and the browser flasher.
